



English

Self-hosted Linux network discovery and live topology map. Real-time device monitoring (ICMP/ARP), model-level fingerprinting (iPhone, Android, cameras, NVR/DVR), evidence-based wiring via LLDP/SNMP, and a dark SOC-style web UI. Defensive use only.

Azərbaycanca

Linux üçün öz serverinizdə işləyən şəbəkə kəşfi və canlı topologiya xəritəsi. Real vaxt cihaz monitorinqi (ICMP/ARP), model səviyyəsində tanıma (iPhone, Android, kamera, NVR/DVR), LLDP/SNMP əsaslı real bağlantılar və tünd SOC üslublu veb interfeys. Yalnız müdafiə məqsədilə.

Türkçe

Linux için kendi sunucunuzda çalışan ağ keşfi ve canlı topoloji haritası. Gerçek zamanlı cihaz izleme (ICMP/ARP), model düzeyinde tanıma (iPhone, Android, kamera, NVR/DVR), LLDP/SNMP tabanlı gerçek bağlantılar ve koyu SOC tarzı web arayüzü. Yalnızca savunma amaçlı.
